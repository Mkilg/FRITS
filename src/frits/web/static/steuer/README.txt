Fehlt einer Provinz ihr Bild, leiht sie sich ein ähnliches (siehe LEIHGABEN in web/steuer.py).

  tisch            Eichentisch von oben (16:9, ohne Transparenz)
  insel            schwebende Insel mit freier Wiese rechts (transparent, 3:2)
  <provinz>-1      Fundament (Stufe 0 im Nebel, Stufe 1)
  <provinz>-2      gebaut (Stufe 1 und 2)
  <provinz>-3      blühend mit Fahne (Stufe 3, alles erledigt)
