Woher kommt das Gold?

  • {{ regeln.GOLD_FUND }} für jede Unterlage, die du sicherst
  • {{ regeln.GOLD_SCHATZ }} für jeden Bonus-Schatz (der kann Steuern sparen)
  • {{ regeln.GOLD_FRAGE }} für jede Frage an die Beraterin
  • {{ regeln.GOLD_GIBTS_NICHT }} für „Gibt's nicht“ (bei wichtigen Unterlagen 0, die fragst du lieber)
  • {{ regeln.GOLD_SIEGEL }} für jedes Siegel, {{ regeln.GOLD_TAGWERK }} für jedes geschaffte Tagwerk
  • Im Drachenkampf zählt deine Serie mal: ×2, ×3 … bis ×{{ regeln.MAX_MULT }}.

Jede Karte zahlt nur einmal aus. Zurücknehmen und neu stempeln bringt kein zweites Gold.
