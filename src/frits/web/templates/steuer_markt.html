Woher kommt das Gold?

  • {{ regeln.GOLD_FUND }} für jede Unterlage, die du sicherst. Im Drachenkampf zählt deine Serie mal: ×2, ×3 … bis ×{{ regeln.MAX_MULT }}.
  • {{ regeln.GOLD_SCHATZ }} für jeden Bonus-Schatz (der kann Steuern sparen)
  • {{ regeln.GOLD_FRAGE }} für jede Frage an die Beraterin, {{ regeln.GOLD_GIBTS_NICHT }} für „Gibt's nicht“ (bei wichtigen Unterlagen 0). Ohne Serie.
  • Ein Siegel bringt 2 und 2 je Fund darin, bis {{ regeln.GOLD_SIEGEL }}. Das Tagesziel bringt {{ regeln.GOLD_TAGWERK }}.
  • Wünsche der Beraterin zahlen {{ regeln.GOLD_FUND }}, sobald eine Datei dranhängt, ohne Serie und für höchstens {{ regeln.WUNSCH_DECKEL }} Wünsche im Jahr.
  • Gold gibt es für die letzten Steuerjahre. Ältere Jahre kannst du nachholen, sie füllen nur nicht den Beutel.

Jede Karte zahlt nur einmal aus. Legst du eine Datei zurück, geht ihr Gold zurück, bis du sie neu verdienst. Ist das Gold schon ausgegeben, geht dein letzter Kauf zurück in den Hafen, so fällt der Beutel nie unter null.
