Woher kommen die Salzkörner?
  • {{ regeln.GOLD_FUND }} für jede Unterlage, die du sicherst. Im Drachenkampf wächst das mit deiner Serie, den Faktor zeigt das Banner im Kampf.
  • {{ regeln.GOLD_SCHATZ }} für jeden Bonus-Schatz (der kann Steuern sparen)
  • {{ regeln.GOLD_FRAGE }} für jede Frage an die Beraterin, {{ regeln.GOLD_GIBTS_NICHT }} für „Gibt's nicht“ (bei wichtigen Unterlagen 0). Ohne Serie.
  • Ein Siegel bringt 1 und 1 je Fund darin, bis {{ regeln.GOLD_SIEGEL }}. Das Tagesziel bringt {{ regeln.GOLD_TAGWERK }}.
  • Wünsche der Beraterin zahlen {{ regeln.GOLD_FUND }}, sobald eine Datei dranhängt, ohne Serie und für höchstens {{ regeln.WUNSCH_DECKEL }} Wünsche im Jahr.
  • Salzkörner gibt es für die letzten Steuerjahre, höchstens {{ regeln.SALZ_DECKEL }} pro Steuerjahr. Ältere Jahre kannst du nachholen, sie füllen nur nicht den Beutel.
  • Es ist ein Beutel für ganz FRITS: Was du hier verdienst, kannst du auch bei Fritte ausgeben, und umgekehrt.

Jede Karte zahlt nur einmal aus. Legst du eine Datei zurück, gehen ihre Salzkörner zurück, bis du sie neu verdienst. Sind sie schon ausgegeben, geht dein letzter Helfer zurück in den Hafen, so fällt der Beutel nie unter null.
