Was in einer Truhe steckt und wie fair das ist

So kommt eine Truhe: Jede Rechnung, Gutschrift, Zahlung, Ausgabe, jedes angenommene Angebot, jede Erinnerung und jede gesammelte Steuer-Unterlage kommt beim Kassensturz in die Truhe. Fünf davon füllen sie. Ungefähr jede achte dieser Karten ist eine goldene Glückskarte und bringt gleich eine eigene Truhe mit. Abgehakte Punkte, Gelerntes, Feierabende und Korrekturen zählen hier nicht.

Die Chancen für das, was drin ist: {% for name, p in chancen.prozent %}{{ p }} % {{ name }}{{ ", " if not loop.last }}{% endfor %}. Spätestens jede 4. Truhe ist mindestens selten, spätestens jede 12. legendär. {% if chancen.geoeffnet %}Bei dir: die nächste seltene spätestens in {{ chancen.selten_in }} {{ "Truhe" if chancen.selten_in == 1 else "Truhen" }}, die nächste legendäre spätestens in {{ chancen.legendaer_in }}.{% endif %}

Was drin sein kann: ein Schatz fürs Zimmer oder ein Hut, ein Gewürz fürs Regal (wenn Platz ist) oder Salzkörner. Die Schätze gibt es nur in Truhen und nie doppelt.

Was in einer Truhe steckt, wird beim Öffnen einmal ausgelost und gespeichert. Neu laden ändert nichts. Truhen laufen nie ab, und nichts davon kostet echtes Geld.

So funktioniert's

Fritte mag einen ruhigen, regelmäßigen Rhythmus. Wenn du in den letzten Tagen Papierkram gemacht hast, ist sie munter. Nach gut einer Woche wird sie gemütlich, nach zwei Wochen döst sie ein bisschen. Mehr passiert nie: Sie wird nicht traurig und nicht krank, und wenn du wiederkommst, freut sie sich.

Kassensturz

Körner × Würze = Salzkörner. Die Würze beginnt bei 1 (mit einem größeren Haus und gutem Ruf auch höher). Gewürze geben Extra-Körner auf passende Karten oder erhöhen die Würze. Die Würze wirkt im Regal von links nach rechts, also lohnt es sich, ein „×“-Gewürz ganz nach rechts zu stellen.

Saisons

Jedes Vierteljahr hat ein Thema: Eine Kartenart bringt dann doppelt so viele Körner. Der Saison-Streifen zeigt den Wochenrhythmus, ein Punkt pro Woche: Das Ziel ist Papierkram in etwa sieben von zehn Wochen, in dieser Saison {{ saison.ziel }} von {{ saison.wochen }}. Gezählt wird, wann FRITS neue Arbeit bemerkt hat, nicht wie viele Salzkörner es waren. Wer das Ziel erreicht, bekommt Salzkörner extra und einen Pokal. Wer es nicht erreicht, verliert nichts.

Gelöschte oder stornierte Vorgänge fallen heraus. Wird eine schon gezählte Rechnung, Gutschrift oder Ausgabe storniert oder gestrichen, ist die nächste passende Karte eine Korrektur ohne Körner, egal in welcher Reihenfolge. Belohnt wird nur, was gute Buchhaltung ausmacht: Belege bald nach dem Eingang eintragen, Rechnungen bald nach der Notiz schreiben, freundlich nachhaken, regelmäßig dranbleiben. Fritte schaut dabei nur auf Daten, die FRITS selbst festhält. Das Datum auf einem Beleg oder einer Rechnung muss einfach stimmen, ein anderes Datum bringt nie mehr.

Fritte ausblenden kannst du in den Einstellungen.
