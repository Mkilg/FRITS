Und wenn doch mal ein Name durchrutscht?

Kein Drama. Das Schwärzen ist eine zusätzliche Vorsicht, keine Pflicht:

  • Datenschutz (DSGVO): Kundendaten für eine Rechnung zu verarbeiten ist ein ganz normaler, erlaubter Zweck. Für den geschäftlichen Einsatz bieten Anthropic und OpenAI einen Vertrag zur Auftragsverarbeitung (AVV) an.
  • Training: Anthropic und OpenAI verwenden Daten, die über ihre API kommen, nach eigenen Angaben nicht zum Trainieren ihrer Modelle. Bei OpenRouter hängt das vom gewählten Modell ab.
  • EU AI Act: Ein Rechnungshelfer wie FRITS fällt unter „minimales Risiko“. Dafür gibt es keine besonderen Pflichten. Was das Gesetz von Firmen erwartet, die KI nutzen, ist ein Grundverständnis, wie KI funktioniert. Genau das übst du hier gerade.

Weniger Daten weiterzugeben ist trotzdem eine gute Gewohnheit: Was nie verschickt wurde, kann auch nirgends verloren gehen.

Das ist eine Einordnung, keine Rechtsberatung.
