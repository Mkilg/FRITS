FRITS startet

Einen Moment, FRITS wird in deinem Browser eingerichtet …

Beim ersten Mal lädt dein Browser etwa 35 MB. Danach muss nichts mehr geladen werden, FRITS startet dann auch ohne Internet. Deine Daten bleiben in diesem Browser auf diesem Gerät.

🔒 Im Browser · gespeichert

FRITS im Browser

Das ist dasselbe FRITS wie die Mac-App, nur ohne Installation. Es läuft komplett in diesem Browser-Tab. Es gibt keinen FRITS-Server: niemand außer dir sieht deine Daten.

  • Wo liegen meine Daten? Im Speicher dieses Browsers auf diesem Gerät. Ein anderer Browser oder ein anderes Gerät sieht sie nicht.
  • Sicherung ist Pflicht. Wenn du die Browserdaten löschst, sind deine Rechnungen weg. Lade regelmäßig eine Sicherung herunter (unten links), zum Beispiel jeden Freitag.
  • Was geht ins Internet? Nur der schon geschwärzte Text an die KI, die du gewählt hast, mit deinem eigenen Schlüssel. Einmalig lädt dein Browser das Schwärz-Modell (ca. 180 MB) von Hugging Face; dabei wird kein Text von dir übertragen.
  • Was fehlt? Der Eingangsordner auf dem Mac und „In Mail öffnen“. Dateien ziehst du einfach ins Fenster oder fügst Text ein.
